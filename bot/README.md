# 🤖 Telegram-бот «Хатм»

Бот для тех, кто читает Коран и хочет разобраться в его смысле:

- 📖 **Все 114 сур** — арабский текст, перевод Э. Кулиева и **тафсир** (толкование) Ас-Саади на русском;
- 💡 **Длинный тафсир** — бот показывает начало и даёт кнопку «Тафсир полностью»;
- 🕌 **40 хадисов имама ан-Навави** — арабский текст и перевод Абдуллы Нирши;
- 📋 **Навигация по аятам** — листать по одному или открыть сетку номеров и прыгнуть к нужному;
- 📊 Для владельца: `/stats` и `/broadcast`.

Всё на русском, тон дружелюбный. Токен и ID владельца хранятся **только** в `bot/.env`.

---

## 1. Что нужно

1. **Node.js 18 или новее** — [nodejs.org](https://nodejs.org) (проверка: `node --version`).
2. **Telegram** — аккаунт, с которого будете управлять ботом.
3. Папка `data/` из корня проекта (`data/quran.js`, `data/hadiths.js`, `data/tafsir.js`).
   Бот читает её напрямую — ничего копировать не нужно, если папка `bot/` лежит внутри проекта.

---

## 2. Получить токен бота

1. Откройте в Telegram **@BotFather**.
2. Отправьте `/newbot`.
3. Придумайте имя (например, «Хатм») и username, заканчивающийся на `bot`
   (например, `hatam_quran_bot`).
4. BotFather пришлёт строку вида:

   ```
   123456789:AAH-пример_токена_из_цифр_и_букв
   ```

   Это и есть `BOT_TOKEN`. Никому его не показывайте.

Если бот уже создан, токен можно получить снова: `/mybots` → ваш бот → **API Token**.

---

## 3. Узнать свой Telegram ID

1. Откройте **@userinfobot** (или **@getmyid_bot**).
2. Нажмите **Start** — бот пришлёт ваш числовой ID, например `123456789`.

Это `OWNER_ID`. Именно этому пользователю будут доступны `/stats` и `/broadcast`.

---

## 4. Создать `.env`

В папке `bot/` создайте файл `.env` (рядом с `package.json`). Проще всего скопировать шаблон:

```powershell
cd D:\projects\hatam\bot
Copy-Item .env.example .env
notepad .env
```

И вписать свои значения:

```env
BOT_TOKEN=123456789:AAH-пример_токена_из_цифр_и_букв
OWNER_ID=123456789
```

Можно указать несколько владельцев через запятую: `OWNER_ID=111111,222222`.

> ⚠️ Файл `.env` уже добавлен в `.gitignore` и никогда не попадёт на GitHub.
> Если токен всё же «утёк» — в @BotFather выполните `/revoke` и получите новый.

---

## 5. Установить зависимости

```powershell
cd D:\projects\hatam\bot
npm install
```

Установятся два пакета: `telegraf` (работа с Telegram) и `dotenv` (чтение `.env`).

> Если на диске C: мало места, кэш npm можно положить на другой диск:
> ```powershell
> npm install --cache D:\npm-cache
> ```

## 6. Проверить без запуска бота

```powershell
npm run check
```

Токен для этой проверки **не нужен**. Ожидаемый результат:

```
📚 Сур: 114
🕌 Хадисов: 42
💡 Тафсир: Тафсир Ас-Саади — 4742 аятов с толкованием
📖 Аятов собрано: 6236, без вида: 0
📏 Самое длинное сообщение с аятом: 3894 символов
✂️  Аятов с сокращённым тафсиром: 203
📏 Самое длинное сообщение с хадисом: 3841 символов
...
✅ Проверка пройдена, можно запускать бота.
```

Затем вторая проверка — все кнопки и callback-данные:

```
кнопок проверено: 5930
частей у хадисов > 1: 2, 30
неизвестные callback: нет
callback > 64 байт: нет
ошибки: нет
```

Что это значит:

- все 6236 аятов собираются в сообщения и **ни одно не превышает лимит Telegram** (4096 символов);
- 203 аята с очень длинным тафсиром показываются сокращённо + кнопка «Тафсир полностью»;
- хадисы 2 и 30 не влезают в одно сообщение, поэтому разбиты на части с кнопками ⬅️ ➡️;
- все кнопки ведут на существующие обработчики.

## 7. Запустить бота

```powershell
cd D:\projects\hatam\bot
npm start
```

В консоли появится:

```
🤖 Бот: @hatam_quran_bot (Хатм)
👥 Пользователей в базе: 0
✅ Бот запущен. Нажмите Ctrl+C, чтобы остановить.
```

Теперь откройте своего бота в Telegram и нажмите **Start**.

Остановить — `Ctrl+C` в консоли.

## 9. Чтобы бот работал круглосуточно

Бот — обычная Node.js-программа: пока она запущена, бот отвечает.

**Вариант А. Свой компьютер.** Просто держите `npm start` запущенным.
Неудобно: при выключении компьютера бот «замолкает».

**Вариант Б. Недорогой VPS (рекомендуется).** Любой сервер с Ubuntu,
Node.js 18+ и 512 МБ RAM достаточно:

```bash
# на сервере
git clone https://github.com/minullinunus-stack/quran.git
cd quran/bot
npm install
nano .env          # вставить BOT_TOKEN и OWNER_ID
npm install -g pm2
pm2 start src/index.js --name hatam-bot
pm2 save
pm2 startup        # автозапуск после перезагрузки
```

Полезные команды: `pm2 logs hatam-bot`, `pm2 restart hatam-bot`, `pm2 stop hatam-bot`.

**Вариант В. Бесплатные хостинги** (Railway, Render, Fly.io) тоже подойдут,
но учтите: файл `bot/storage.json` (список пользователей для `/stats` и
`/broadcast`) должен лежать на постоянном диске, иначе статистика будет
обнуляться при каждом перезапуске.

## 10. Если что-то не так

| Сообщение | Причина и решение |
|---|---|
| `❌ Не задан BOT_TOKEN` | Нет файла `bot/.env` или в нём пустой `BOT_TOKEN`. Скопируйте `.env.example` → `.env`. |
| `401: Unauthorized` | Токен неверный или отозван. Возьмите новый у @BotFather (`/revoke`). |
| `409: Conflict` | Бот уже запущен в другом месте (вторая консоль, pm2, другой сервер). Остановите лишний экземпляр. |
| `Не найден файл данных: ...` | Бот запущен не из `bot/`, либо папки `data/` нет рядом. Запускайте из `bot/` или укажите `DATA_DIR` в `.env` (абсолютный путь к папке `data`). |
| `ENOSPC` при `npm install` | Мало места на диске. Используйте `npm install --cache D:\npm-cache`. |
| Кнопки не отвечают | Проверьте, что процесс жив (`npm start`), и в консоли нет ошибок. |
| `/stats` пишет «только владельцу» | `OWNER_ID` не совпадает с вашим ID. Узнайте ID у @userinfobot. |

## 11. Как устроен код

```
bot/
  package.json        зависимости и команды npm
  .env.example        шаблон настроек (без секретов)
  .env                ВАШИ токен и ID — в git не попадает
  storage.json        база пользователей и статистики (создаётся сама)
  src/index.js        запуск бота, команды, обработчики кнопок
  src/ui.js           тексты сообщений и клавиатуры
  src/data.js         загрузка data/quran.js, hadiths.js, tafsir.js
  src/format.js       экранирование HTML, нарезка длинных текстов
  check-ui.js         проверка всех кнопок и лимитов Telegram
```

Данные не дублируются: бот читает те же файлы `data/*.js`, что и сайт,
поэтому правки текста или тафсира сразу видны и на сайте (после `python build.py`),
и в боте (после перезапуска).
