# Обновление Android-приложения

Приложение проверяет `https://hatam-mauve.vercel.app/downloads/latest.json`
при запуске и по кнопке. Если `versionCode` больше установленного, появляется
«Обновить приложение». APK скачивается через браузер; пользователь подтверждает
установку в Android. Ошибка сети не мешает офлайн-чтению.

При каждом выпуске:

1. Увеличить `versionCode` и `versionName` в `app/build.gradle.kts`.
2. Собрать `assembleDebug` для текущего канала прямой установки. Использовать
   тот же сохранённый ключ подписи: смена ключа не позволит установить обновление
   поверх прежнего приложения. Не добавлять ключи или пароли в Git.
3. Проверить APK через `apksigner verify`, убедиться, что подпись совпадает с
   предыдущим выпуском. Скопировать APK в `downloads/Hatam-<versionName>.apk`.
4. Обновить `downloads/latest.json`: `versionCode`, `versionName` и `apkUrl`
   должны соответствовать готовому APK. Обновить ссылку в `index.html` и
   `src/app.html`. Старые ссылки должны оставаться рабочими.
5. Опубликовать APK и JSON одним коммитом, проверить завершение деплоя Vercel.
   Проверить старую установленную версию: появилась кнопка обновления; после
   установки новая версия сообщает, что обновлений нет. Проверить сохранение
   прогресса. Не удалять приложение перед обновлением.

Сборка сама синхронизирует сайт в assets и удаляет из APK ссылку на скачивание
приложения. На сайте эта ссылка сохраняется. Не пересобирать `index.html` из
устаревшего `src/app.html` без отдельной синхронизации исходника: готовый HTML
содержит дополнительные данные и разделы.

Текущий APK подписан отладочным ключом для прямой установки. Для магазина нужен
отдельно подготовленный релизный канал с постоянной подписью.
