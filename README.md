# Хатм — Коран, трекер хатма и 40 хадисов ан-Навави

Одностраничное приложение: трекер хатма (30 джузов), полный текст Корана с переводом
на русский, тафсир Ас-Саади и сборник «40 хадисов» имама ан-Навави.

Работает офлайн, ничего не отправляет в сеть, разрешений не требует.

## Возможности

- **Трекер хатма:** 30 джузов, процент, прогресс сохраняется в браузере.
- **Коран:** 114 сур, арабский текст и перевод Э. Кулиева, поиск суры.
- **Тафсир:** под каждым аятом кнопка «Тафсир» — толкование раскрывается
  и сворачивается стрелкой (по умолчанию скрыто).
- **Размер текста:** кнопки A− / A+ в разделах «Коран» и «Хадисы»,
  от 85 до 200 %, выбор запоминается.
- **42 хадиса ан-Навави:** арабский текст, перевод, отметки о прочитанном.

> Русского перевода тафсира Ибн Касира в открытых источниках нет (на quran.com
> он есть только на арабском и английском). Поэтому в приложение добавлен
> русский тафсир **Ас-Саади** — он ближе всего по содержанию. Арабский оригинал
> Ибн Касира можно добавить по запросу.

## 1. Запуск как сайт

Открыть `index.html` двойным кликом — работает и без сервера.
Для проверки PWA (установка, офлайн-кэш) нужен локальный сервер:

```powershell
cd D:\projects\hatam
python -m http.server 8123
# открыть http://localhost:8123/index.html
```

### Открыть на телефоне

**Способ 1 (проще):** отправить себе `index.html` в мессенджере, скачать на телефон
и открыть файл в Chrome. Так как весь текст внутри одного файла, Коран и хадисы
заработают без интернета.

**Способ 2:** тот же Wi-Fi, что у компьютера:

```powershell
cd D:\projects\hatam
python -m http.server 8080 --bind 0.0.0.0
```

На телефоне открыть `http://<IP-компьютера>:8080/index.html`
(IP узнать командой `ipconfig`). Если не открывается — разрешить Python
в брандмауэре Windows.

Кнопка «Установить» появляется в шапке, когда браузер готов установить приложение
(Chrome/Edge, HTTPS или localhost). На Android это «Добавить на главный экран» —
приложение открывается без адресной строки, как обычное.

## 2. Сборка APK / AAB для RuStore

Нужен **Android Studio** (любая актуальная версия, JDK 17 идёт в комплекте).
Сборка из этой папки без Android Studio не заработает: здесь нет Gradle Wrapper
(`gradlew`), его создаёт Android Studio при первом открытии проекта.

1. Открыть папку `android/` в Android Studio: **File → Open** → выбрать `android`.
2. Дождаться Gradle Sync (скачает Gradle 8.9, AGP 8.7.3, зависимости).
3. Проверить `applicationId` в `android/app/build.gradle.kts` — он должен быть
   уникальным и больше не меняться: `ru.hatam.app`.
4. Подключить телефон (или эмулятор) и нажать **Run ▶** — приложение запустится.

### Подписанный файл для магазина

**Build → Generate Signed App Bundle / APK…**

- Android App Bundle (`.aab`) — для RuStore, рекомендуется;
- APK — если нужен файл для прямой установки.

При первом релизе создать keystore (**Create new…**):

```powershell
keytool -genkeypair -v -keystore hatam-release.jks -alias hatam ^
        -keyalg RSA -keysize 2048 -validity 10000
```

> Сохраните `hatam-release.jks` и пароли. Потеря ключа = невозможность обновлять приложение.

Либо прописать подпись в Gradle (пароли — через переменные окружения):

```kotlin
// android/app/build.gradle.kts
android {
    signingConfigs {
        create("release") {
            storeFile = file("hatam-release.jks")
            storePassword = System.getenv("KEYSTORE_PASSWORD")
            keyAlias = "hatam"
            keyPassword = System.getenv("KEY_PASSWORD")
        }
    }
    buildTypes {
        release { signingConfig = signingConfigs.getByName("release") }
    }
}
```

Сборка из консоли:

```powershell
cd android
.\gradlew.bat bundleRelease
# результат: app\build\outputs\bundle\release\app-release.aab
```

### После правок сайта

Сайт встроен в APK, поэтому перед каждой сборкой копируйте его в assets:

```powershell
cd android
powershell -ExecutionPolicy Bypass -File .\sync-assets.ps1
```

И поднимайте `versionCode` / `versionName` в `app/build.gradle.kts`.

## 3. Публикация в RuStore

1. Зарегистрироваться в [RuStore Console](https://console.rustore.ru) (физлицо или самозанятый тоже может публиковать бесплатные приложения).
2. Создать приложение → загрузить подписанный `.aab` (или `.apk`).
3. Заполнить карточку:
   - **Название:** Хатм — Коран и хадисы
   - **Короткое описание (до 80):** Трекер хатма, Коран с переводом и 40 хадисов ан-Навави
   - **Полное описание:** см. текст ниже
   - **Категория:** Книги / Образование
   - **Возрастной рейтинг:** 0+
   - **Иконка:** `android/store/icon-512.png` (512×512 PNG)
   - **Скриншоты:** минимум 2 (сделайте с телефона: трекер, список сур, чтение суры, хадисы)
   - **Политика конфиденциальности:** https://hatam-mauve.vercel.app/privacy.html
     (не забудьте заменить e-mail в `privacy.html` перед публикацией).
4. Отправить на модерацию (обычно 1–3 рабочих дня).

Требования магазина периодически меняются (минимальный `targetSdk`, форматы файлов) —
актуальные условия всегда указаны в консоли RuStore перед загрузкой.

### Готовое описание для карточки

> **Хатм — Коран и хадисы**
>
> Приложение для тех, кто читает Коран и совершает хатм.
>
> • Трекер хатма: 30 клеток по числу джузов, прогресс в процентах, отметки сохраняются.
> • Полный текст Корана: 114 сур, арабский текст и перевод на русский язык, удобный поиск суры.
> • 40 хадисов имама ан-Навави: арабский текст и перевод, отметки о прочитанном.
>
> Приложение работает офлайн, не содержит рекламы, не собирает персональные данные
> и не запрашивает разрешений.

## 4. Публикация в интернете (GitHub + Vercel)

- **Сайт:** https://hatam-mauve.vercel.app
- **Репозиторий:** https://github.com/minullinunus-stack/quran
- **Хостинг:** Vercel, проект `hatam`, продакшн-ветка `master`.

Репозиторий подключён к Vercel: каждый push в `master` автоматически запускает
новый деплой (обычно 1–2 минуты). После правок сайта:

```powershell
cd D:\projects\hatam
python build.py
powershell -ExecutionPolicy Bypass -File .\android\sync-assets.ps1
git add -A
git commit -m "Что изменилось"
git push
```

Vercel сам пересоберёт и обновит сайт. Service worker кэширует приложение,
поэтому после крупных правок поднимайте версию в `sw.js` (`hatam-v4` → `hatam-v5`),
чтобы у пользователей обновился кэш.

На Vercel уходит только готовый сайт: `data/`, `src/`, `android/` исключены
через `.vercelignore`.
